#
# The inference stack below is the MEASURED import closure of
# sbr.production.submission.infer, pinned to the versions in
# research/FINAL_REPRODUCIBILITY_MANIFEST.json -- the exact set the reported

# tests/test_requirements_cover_runtime.py re-measures the closure and fails if
# this file drifts from what the code actually imports.
