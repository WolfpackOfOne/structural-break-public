# WAVE 5 — OFFLINE RESEARCH ENVIRONMENT
#
# THIS FILE IS NOT THE PRODUCTION ENVIRONMENT AND MUST NEVER BE UPLOADED.
#
# The root `requirements.txt` defines the cloud runner environment: `crunch push`
# uploads it and the runner builds from it ("using original file:
# requirements.txt"). LB-002 died in `infer()` because a library the model needed
# was declared in a file the runner does not read. The inverse mistake is now
# available to us in the other direction: putting a research library into the
# runtime file would ship a 1 GB torch install to a runner that never imports it.
#
# RULE (Wave-5 charter §7): production dependencies change only when a model that
# actually needs them is promoted toward submission, and then only through the
# measured-import-closure procedure that `tests/test_requirements_cover_runtime.py`
# enforces. Nothing here is production until that happens.
#
# Install into a SEPARATE venv:
#     uv venv --python 3.12 .venv-wave5
#     VIRTUAL_ENV=.venv-wave5 uv pip install -r research/requirements-wave5.txt
#
# Python 3.12 is deliberate: it is the runner's Python, so anything that resolves
# here resolves there. Every pin below was installed and imported on
# Linux/x86_64/cp312 on 2026-08-22; see research/PACKAGE_CAPABILITY_MATRIX.md.
